# Design
## Direction
User-approved dark and restrained portfolio. A quiet digital exhibition: large editorial typography, real evidence, fine rules and a small interactive sculpture. The approved brief takes precedence over generated alternatives.
## System
Charcoal #161819, warm text #eeece6, secondary #a6aaa9, blue #a1c7ff. Self-hosted Manrope. Maximum content width 1240px. Desktop gutters 56px; mobile 20px. Large image-led Wintor feature followed by text-led museum stories. Avoid fabricating assets.
## Interaction
Render-on-demand Three.js with three forms. Ordinary HTML buttons mirror canvas selection. Reduced motion and missing WebGL retain static geometry. Main content is HTML with no JavaScript dependency. Small image tilt only with a fine pointer.
## Verification
Desktop/mobile browser review, static internal-link check, production build, published URL verification. No tracking or external font requests.
